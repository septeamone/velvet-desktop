# Velvet TV

Российское ТВ и радио в одном аккуратном приложении для Windows. Сделано на Tauri 2.

- ТВ: десятки каналов, выбор качества, программа передач, картинка в картинке, избранное, поиск.
- Радио: 400+ станций из России и 28 стран, плавные переходы, выбор качества, названия песен, визуализатор (каталог из расширения Velvet Radio 1.5).
- Тёмная и светлая тема, обновления по сети.
- Встроенный локальный прокси открывает потоки без отключения защиты браузера и без VPN у зрителя.
- Обновления приходят через GitHub Releases (подписаны ключом).

## Разработка

```
pnpm install
pnpm tauri dev          # окно приложения
pnpm tauri build        # установщик (NSIS)
```

Нужны Node.js, pnpm, Rust и Microsoft C++ Build Tools.

## Программа передач

Каталог радио собирает `tools/gen-radio.mjs` из снимка расширения (`_radio-source/`, в репозиторий не входит).

`tools/build-epg.py` собирает компактный `data/epg.json` из открытых XMLTV-файлов. Его запускает
GitHub Actions каждые 4 часа (`.github/workflows/epg.yml`), приложение читает файл напрямую с GitHub.
Для каналов Rutube программа берётся у Rutube в реальном времени.
